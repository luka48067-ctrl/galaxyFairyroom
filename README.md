# GALAXY FAIRY ROOM

銀河の妖精シェリルの活動案内サイト（試作）。
レーベルサイトではなく、「いま何してる？どこで逢える？どう届ける？」が一発でわかる部屋。

## 開き方

1. `index.html` をブラウザで開く（ダブルクリックでOK）
2. ネットに置くなら、このフォルダごと GitHub Pages / Netlify / Cloudflare Pages に上げる

## 入っているもの

- 日本時間と「いまの枠」目安
- YouTube / REALITY / 銀河STAGE MusicFES の時間軸
- リクエスト経路（マシュマロ・ラブレター・DM・スパチャ）
- 交流（X・サイト・Discord枠）
- 子ども食堂と作曲のつぶやき
- 記録（エトワールセトリ / 銀河の記憶）
- 歌詞・DANCE・曲・RECORD の棚
- リンクハブ
- サポーター特典の骨格
- NEWS / つぶやき / お便り
- シェリクイズ（9月号サンプル）
- 覚書（この端末のブラウザに保存 + テキスト書き出し）

## シェリが直すところ

`index.html` をテキストエディタで開いて、次を書き換える。

- 次回フェスのテーマと出演者（`#fesSlots`）
- Discord / マシュマロの正式URL
- サポーター特典の最新内容
- NEWS とお便り
- クイズの中身は `app.js` の `QUESTIONS`

覚書は公開サイト本体には送られない。自分のブラウザにだけ残る下書き箱。
みんなに見せたい文章は、書き出して X や note に貼るか、`index.html` の該当欄にコピペしてね。
